# Voice Processing & Final Delivery

A practical voice-processing project showing the original dialogue, a processed delivery master, and a short-section A/B comparison.

## Project overview

The dialogue excerpt is processed for final delivery using compression, EQ, de-essing, and final limiting. The project presents the original and finished master alongside an A/B file that alternates between corresponding short sections.

## Audio assets

- **Original dialogue used in the comparison:** [Gain-adjusted flat recording](001_Blood%20Hunt_CH1_Excerpt_Flat_NormalisedToMatch.mp3)
- **Processed master:** [Finished deliverable](001_Blood%20Hunt_CH1_Excerpt_Mastered.mp3)
- **A/B comparison:** [Alternating original and processed sections](001_Blood%20Hunt_CH1_Excerpt_AB%20Comparison.mp3)

The flat recording linked here is gain-adjusted for the comparison. The untouched original is in Project 1.

## A/B comparison method

The comparison alternates between short sections of dialogue to make listening comparisons easier. Each section starts with the original audio, followed immediately by the processed deliverable master.

The original in the comparison has been gain-adjusted to match the processed version's peak level **at one point in the comparison only**. The individual edited sections have not been separately peak-matched, and the comparison is **not loudness-matched**. Perceived loudness can therefore vary between the original and processed sections. No additional processing was applied to force a section-by-section match.
